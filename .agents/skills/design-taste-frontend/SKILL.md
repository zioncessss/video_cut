# tasteskill: Anti-Slop Frontend Skill

> Every rule below is contextual. First read the brief, then pull only what fits.

## 0. BRIEF INFERENCE (Read the Room Before Anything Else)
- State one-line "Design Read": "Reading this as: <page kind> for <audience>, with a <vibe> language, leaning toward <aesthetic>."
- Avoid clichés: no generic purple gradients, no cluttered badges/eyebrows everywhere, no redundant explanatory paragraphs, clean layout with high intentionality.

## 1. CORE DIALS
- DESIGN_VARIANCE: 5-7 (Clean, orderly, intentional)
- MOTION_INTENSITY: 3-5 (Subtle, responsive, crisp tactile feedback)
- VISUAL_DENSITY: 4-6 (Clean workspace tool, data breathes, no useless fluff)

## 2. ELIMINATE FLUFF & CLUTTER (Clean UI Rule)
- Ruthlessly delete meaningless modules, useless cards, and verbose explanatory text.
- If an explanation doesn't help the user take action or understand key state, CUT IT.
- Keep only functional controls, crisp status indicators, and actionable buttons.
- Clean typography: unified scales, max 1 accent color, standard corner radius, high contrast WCAG AA.
- Button text on one line, single primary CTA intent per surface.

## 3. PROFESSIONAL WORKSPACE UX (10-Year PM & Designer Standard)
- Clear visual hierarchy: Stage (Preview/Playback) > Timeline/Subtitles > Controls/Parameters.
- Consistent styling, refined borders, gentle tactile active states.
- Clear empty, loading, and error states.

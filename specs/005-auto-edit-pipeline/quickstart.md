# Quickstart Validation: 005-auto-edit-pipeline

端到端验证指南。前置：FFmpeg 在 PATH、`.venv` 可用、后端 `python launcher.py` 或 `uvicorn` 启动、`storage/glossary.json` 存在。

## V1 界面动作收敛（Story 1）

1. 启动前后端，进入视频剪辑页，选择口播视频。
2. **期望**: 工具栏仅一个主动作按钮「智能剪辑」；无「单步纠错」按钮。
3. 点击「智能剪辑」→ 进度走完 → 字幕加载。已就绪状态下按钮仍叫「智能剪辑」（无「重新」字样），点击可重跑。

## V2 AI 高亮词 + 词库双引擎（Story 2）

1. 准备含「从今年九月份开始湖州驾校」「自建五万平训练场」「一把过」的口播视频，执行智能剪辑。
2. **期望**: 字幕列表中「九月份」（AI）、「五万平」（AI/词库）、「一把过」（词库）均为高亮词。
3. 断网或改错 base_url 后强制重跑 → **期望**: 降级提示如实（引擎标识含 fallback），词库命中词仍在，无假装成功。

## V3 时间轴高亮词可视化调整（Story 3）

1. 展开「字幕与时间轴轨道」，任一句下方可见高亮词 chip（带来源徽标）。
2. 删除一个词 → 添加一个新词 → 渲染成片。
3. **期望**: 成片中新词按主题色高亮放大，被删词恢复普通样式；重开工程修改仍在（持久化）。

## V4 四类分镜与体验空镜迁移（Story 4）

1. `python scripts/migrate_005.py`（试运行）核对 diff → `--apply` 执行。
2. **期望**: 素材库四类标签为「口播分镜/场地空镜/体验空镜/教学学车空镜」；`storage/materials/experience/` 存在且旧目录已迁；重跑脚本提示无需迁移（幂等）。
3. 含「体检拍照」字幕的工程 → 匹配到 experience 类素材，历史 medical 引用不失效。

## V5 AI 分镜决策与转场（Story 5）

1. 用真实口播固件（`tests/fixtures/` 萧山报价视频文本，含「不要这个数只要这个数」）执行智能剪辑（enable_scene_decision=true）。
2. **期望**：开场钩子句不切（真人出镜）；「试学一节课」句出现 experience 空镜区间与理由；**「不要这个数，也不要这个数，只要这个数」句强制不切**（后端校验兜底）；「滴滴我」CTA 句不切；不相邻两句连续切；全片空镜占比 ≤40%（实测约 23%）。
3. 策略切 `transition_style="fade"` 渲染 → 成片转场处叠化，**语音全程连续无断裂**（音轨来自口播原片）。
4. 时间轴展示 hook/body/cta 叙事分段着色，空镜可手动改分类/换素材/调时长。
5. 单测固定样本：`pytest tests/test_scene_decision.py` 验证 JSON 裁剪（duration 越界、非法分类、手势句误判被裁）。

## V6 批量剪辑与工作台联动（Story 6）

1. 素材库多选 2~3 个口播视频 → 发起批量剪辑。
2. **期望**: 队列并发 ≤ recommended_concurrency；逐项进度可见；故意放一个损坏视频 → 该项 failed 并展示真实错误，其余完成。
3. 点击任一完成项 → 进入单视频工作台 → 改字幕重渲染 → 返回批量列表状态为最新。

## V7 横幅水印默认关闭 + 封面（Story 7/8）

1. 新工程渲染成片 → **期望**: 无标题横幅、无水印。
2. 策略工坊开水印再渲染 → 水印出现。
3. 工程详情选帧设封面 → 重开工程封面仍在；AI 封面入口 → 提示「规划中」，无伪结果。

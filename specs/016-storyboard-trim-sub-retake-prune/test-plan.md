# 测试规划与执行规范：分镜切入裁剪与口播重读物理裁剪全链路测试方案

**测试版本**: Feature 016 (Storyboard Trim & Subtitle Retake Pruning)  
**责任角色**: 功能与质量测试工程师 (QA & SDET)  
**测试范围**:
1. 口播重读定位算法、前缀重叠（$\ge 75\%$）与排比句/长句防误剪安全网
2. 原口播视频真正物理裁剪（音画切片拼接与 15ms afade 防爆音）
3. 自主分镜切入时间与素材截取 In 点 (`source_start_time`) 滤镜与静音模式
4. 任意时间段字幕新增、时间戳微调（防倒置校验）与高亮词全生命周期无损
5. 所见即所得 (Live WYSIWYG) 实时跳播、实时贴片与浅灰微条就地折叠恢复
6. 全链路前后端回归与真实压制断言

## 1. 测试用例设计矩阵 (Test Case Matrix)

| 用例编号 | 功能模块 | 测试目的与场景 | 预置输入与操作 | 预期结果与判定标准 | 优先级 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **TC-PRUNE-001** | 口播重读识别 | 典型前缀重复口误识别 | 模拟输入读错前句（如“我们今天去顺达” 0.0~1.8s）紧跟修正正句（“我们今天去顺达驾校学车” 2.2~4.8s） | 准确识别前句为 `retake_discard`，识别置信度 $\ge 0.85$，被裁剪区间精准匹配前句时间 | P1 (MVP) |
| **TC-PRUNE-002** | 防误剪安全网 | 快速排比连读保护 (gap < 0.2s) | 输入同前缀排比连读句（如“这个点位很重要，这个点位必须记牢”，间隔 0.1s） | 触发排比连读守卫，两句均被完整保留，严禁误判为口误剔除 | P1 (MVP) |
| **TC-PRUNE-003** | 防误剪安全网 | 独立完整语义长句保护 ($\ge 9$ 字) | 输入长句前缀相似（如“我们今天在顺达驾校集合，我们今天在顺达驾校组织科目二考核”） | 触发长句语义守卫，不因前缀高相似而误删长句 | P1 (MVP) |
| **TC-PRUNE-004** | ASR 合并阻断 | 短句合并阶段前缀重读阻断 | 在 `merge_short_segments` 中输入前缀相同相邻短句（$< 1.5\text{s}$） | `is_retake_guard` 生效，强制阻断两句粘连，保留独立片段供粗剪算法识别 | P1 (MVP) |
| **TC-VIDEO-001** | 视频物理裁剪 | 真实音画物理裁剪与时长扣减 | 针对时长 15.0s 的口播视频，标记剔除第 1 句（时长 2.5s），执行物理切片拼接 | 导出的成片 MP4 物理文件时长严格等于 $15.0 - 2.5 = 12.5\text{s}$，严禁仅删文字不切视频 | P1 (MVP) |
| **TC-VIDEO-002** | 接缝平滑度 | 拼接断点音频淡入淡出（防爆音） | 检查 FFmpeg 复合滤镜图 | 拼接点各保留片段末尾与起始注入 15ms `afade` 交叉过渡，杜绝杂音与爆破音 | P1 |
| **TC-BROLL-001** | 分镜素材裁剪 | 素材自身截取 In 点 (`source_start_time`) | 设置素材从 1.8s 截取，切入主视频 2.0s~5.0s | FFmpeg 滤镜生成包含 `trim=start=1.8:duration=3.0`，起始帧准确偏移 1.8s | P2 |
| **TC-BROLL-002** | 分镜音轨隔离 | 分镜纯画面覆盖与完全静音 | 设置分镜切入主视频 | 分镜音频被强制剥离 (`an=1` 或仅映射主视频音频 `[0:a]`)，成片仅保留口播原声旁白 | P2 |
| **TC-SUB-001** | 字幕时间微调 | 字幕起止时间毫秒级微调与持久化 | 修改第 2 句字幕时间戳（从 3.0~5.0s 改为 3.2~5.5s）并保存 | SQLite 数据库准确更新时间，后续字幕时间轴与紧凑时间轴实时重算 | P2 |
| **TC-SUB-002** | 时间校验 | 起止时间防倒置与最小间隔校验 | 尝试设置 `end <= start` 或 `end - start < 0.05` | 前端就地高亮提示阻断保存，服务端防御校验抛出明确错误 | P2 |
| **TC-SUB-003** | 字幕新增 | 任意时间段插入新字幕 | 点击“+ 插入字幕”，在两句中间插入新字幕并保存 | 新字幕准确插入列表，起止时间与文本成功持久化，无主键冲突 | P2 |
| **TC-SUB-004** | 高亮词完整性 | 新增与修改字幕高亮词全生命周期无损 | 新增字幕包含专有词（如“顺达驾校坡道定点”），不传 highlight_words | 后端 `build_highlight_words` 规则就地自愈提取高亮词，导出成片含高亮颜色标签 | P1 (底线) |
| **TC-UI-001** | 交互体验 | 轻量浅灰微条就地折叠 | 标记剔除口误片段 | 界面无顶部横幅扰乱，被裁口误就地折叠为轻量浅灰微条（显示删除线文字与时长） | P3 |

| **TC-UI-003** | 实时预览 | 播放器虚拟跳播 (Virtual Jump-Cut) | 播放器播放至被裁口误起始点 | 毫秒级直接跳过被裁区间至 `end_time`，零后台转码等待，所见即所得 | P3 |
| **TC-UI-004** | 实时贴片 | 播放器实时分镜贴片叠加同步 | 播放器播放至分镜切入时间窗 | 静音空镜视频基于 `source_start_time` 同步贴片渲染，音频持续播放口播原声 | P3 |
| **TC-BUILD-001** | 构建与工程 | 前端 TypeScript 编译与打包 | 运行 `pnpm build` | 0 类型错误，产物正常构建输出 | P1 |
| **TC-REGRESS-001** | 回归验证 | 全量自动化测试套件执行 | 运行全量核心单测与集成测试 | 100% 绿灯通过，无偶发失败 | P1 |

## 2. 自动化测试实施设计与套件编排
为了确保测试的客观性与严密性，除了既有的 5 个专用测试模块外，新增集中式端到端质量验证套件：
`tests/test_qa_storyboard_and_retake_matrix.py`
涵盖：
1. 真实 ASR 重读阻断守卫全边界测试；
2. 前缀重叠度、排比连读与语义长句三层安全网算法隔离验证；
3. 真实 FFmpeg 物理裁剪与时长扣减断言；
4. 分镜 In 点与完全静音滤镜结构断言；
5. 字幕新增、微调与高亮词全生命周期无损验证；
6. 剔除与一键恢复的虚拟时间轴重投影数学验证。

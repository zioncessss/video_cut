# Quickstart Validation Guide: 智能剔除口播视频头尾动作与口误重说 (009-prune-retakes-silence)

## 1. 验证目标

验证手机录制口播视频在导入并进入自动剪辑管线后：
1. 首句人声前的准备废动作（保留 0.2s 气口）被自动标记剔除；
2. 末句收音后的伸手关机废动作（保留 0.25s 气口）被自动标记剔除；
3. 出现的口误重讲与改口词句遵循“留后弃前”规则自动剔除前驱废句；
4. 中段无声长冷场（> 1.2s）被自动压缩并保留 0.3s 标准呼吸停顿；
5. 工作台播放器实时无缝跳过剔除段，支持一键反选恢复；
6. FFmpeg 导出视频声画无缝拼接且无爆音。

---

## 2. 自动化单元与集成测试验证

在终端执行自动化测试：

```powershell
# 1. 运行智能粗剪算法单测（覆盖头尾剔除、口误重说留后弃前、中段气口保留）
pytest tests/test_auto_prune_engine.py -v

# 2. 运行真实项目 5 部口播视频回归测试
pytest tests/test_real_projects_prune.py -v

# 3. 运行视频导出无爆音与声画对齐测试
pytest tests/test_prune_video_export.py -v
```

## 3. 端到端界面验收流程 (Manual Walkthrough)

1. 打开桌面端应用，进入【素材库】(`/upload`)，选择手机录制的口播原片（如测试用例《湖州驾校大改革》）；
2. 点击【一键自动剪辑】，系统自动完成 ASR 转写并触发 `AutoPruneEngine`；
3. 进入【剪辑工作台】(`/editor`)：
   - 观察字幕列表顶部：首句之前的 0.0s~0.8s 被标记为“已剔除 (头部动作)”；
   - 观察字幕列表末尾：末句之后的 26.4s~27.8s 被标记为“已剔除 (尾部动作)”；
   - 观察口误段落：第 0 句“从今年九月份开始啊”被标记为“已剔除 (口误重说)”，第 1 句“湖州驾校从今年九月份开始”正常高亮保留；
   - 观察长停顿段落：中间停顿点被压缩，但听感上保留了舒适自然的 0.3 秒换气间隔；
4. 点击播放按钮：
   - 播放器起播瞬间无卡壳，直接顺畅起播第 1 句；
   - 遇到已剔除片段时指针自动平滑跳过；
5. 点击被剔除的第 0 句右侧【恢复】按钮：
   - 划线消失，状态变为正常保留，时间轴自动扩展；
6. 点击【导出视频】：
   - 生成的成片时长自动缩短，音频无喀嗒爆音（pop noise），声画字幕精准同步。

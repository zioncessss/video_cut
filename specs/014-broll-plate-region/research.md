## 1. 调研目标与未知项拆解 (Research Objectives)

本特性的核心是在零人工配置负担的前提下，实现“素材入库带属地、ASR 智能识城市、分镜绝对防穿帮”的完整闭环。需要通过本次调研明确以下关键技术细节：

1. **浙江省 11 地级市与下辖区县地名库结构**：如何高效、高准确率地覆盖市、区、县及高频考场词，避免误判与冲突？
2. **ASR 文本中地名实体的全自动推导机制**：在无昂贵外部 NER 依赖的纯本地轻量引擎下，如何实现高置信度的地名打分与目标城市判定？
3. **SQLite 模式兼容与向前迁移**：如何在保持已有 `videocut.db` 权威存储不被破坏、存量素材零丢失的前提下无缝追加 `plate_region` 与 `target_region`？
4. **分镜调度引擎的绝对防穿帮与有限素材复用算法**：当同地市素材充足 vs 匮乏时，调度算法如何保证 0 跨区穿帮且画面节奏平滑？
5. **C 端轻量交互设计**：素材库上传与卡片原地治理如何在 TailwindCSS 浅色质感下保持简洁直观？

### 决策 2：ASR 地理感知自动评分算法 (Automatic Region Scoring Algorithm)

- **决定**：遍历 ASR 校正后字幕句子列表，构建地名频次与词距打分机制：
  1. **车牌代号直接命中**（如“浙E”）：+10 分；
  2. **地级市名命中**（如“湖州”）：+8 分；若相邻窗口出现“学车/驾校/考场/练车/教练”复合词，额外 +5 分；
  3. **区县名命中**（如“长兴”/“德清”）：+6 分；
  4. **考场名命中**（如“场口”/“大港”）：+6 分。
- **冲突处理与兜底**：
  - 汇总各城市得分，最高分者即为 `target_region`；
  - 若全文无任何地名提及（纯驾驶动作讲解）：自动回退至系统默认配置（默认优先采用 `浙E · 湖州` 或素材库中素材储备最多的地市），绝不阻断剪辑流程。

### 决策 3：SQLite 权威库平滑迁移策略 (Zero-Downtime SQLite Schema Evolution)

- **决定**：
  - 在 `backend/app/db/session.py` 初始化数据库阶段，使用 `PRAGMA table_info(materials)` 探测是否存在 `plate_region` 字段；若无，自动执行 `ALTER TABLE materials ADD COLUMN plate_region TEXT NULL`。
  - 在 `projects` 表同理追加 `target_region TEXT NULL`。
  - 存量历史素材 `plate_region` 为 NULL，在接口与自愈逻辑中映射为 `"未标注"`，渲染时展示淡灰色轻量待标记徽章，既不报错也不影响原有逻辑。

---

### 决策 4：分镜调度防穿帮与素材复用机制 (Strict Anti-Leak B-roll Policy)

- **决定**：
  - 在 `editor.py` 与 `scene_decision.py` 中，根据 `target_region` 严格建立同城候选池：
    `city_candidates = [m for m in all_materials if m.category == broll_cat and m.plate_region == target_region]`
  - **调度逻辑**：
    1. **充足（>= 需切段数）**：打乱后依序抽取，相邻段不重复，保证丰富度；
    2. **不足（1 <= 数量 < 需切段数）**：循环复用同市素材（截取不同时间偏移），绝不允许跨市借用；
    3. **零素材（= 0）**：自动降级为“保留口播真人画面”（不切入空镜），在分镜决策中标记 `broll_category=None, reason="本市空镜素材不足，坚守防穿帮底线保留口播"`。
  - **防穿帮率**：理论保证 0% 跨地市车牌泄漏。

### 决策 5：前端 C 端极简交互 (Frontend Asset & Editor UX)

- **决定**：
  - **上传控制区**：仅当用户选中 `venue`（场地空镜）或 `lesson`（教学学车空镜）标签页时，在操作工具栏（或拖拽框上方）展现精美的原生样式单选 Select 下拉列表：
    `[ 浙E · 湖州  ▼ ]`
  - **持久化上次记忆**：通过 `localStorage` 记录用户最后选择的城市，下次上传自动预填，避免重复选点；
  - **卡片原地编辑**：在素材卡片底部或顶部角标提供轻量点击交互，允许一键弹出下拉菜单改签城市，调用轻量 API 更新，无需整页重载。

## 3. 风险与缓解预案 (Risks & Mitigations)

| 潜在风险 | 影响等级 | 缓解预案 |
|---|:---:|---|
| 地名简称重名（如柯城 vs 柯桥，越城 vs 鹿城） | 低 | 建立严格的词长优先（长词优先匹配）与地级市归属绑定，避免模糊子串误伤 |
| 用户上传了没有车牌的场地空镜却被强制要求选地市 | 低 | 用户决策 Q2 已明确：即使无车牌也归属到具体训练场地所在城市，保持全省素材库严格地域归属 |
| 单市素材极少导致视频无法切空镜 | 中 | 调度器实行安全回退（口播真人画面），同时在剪辑工作台界面给予温和提示：“当前城市湖州空镜较少，已自动保留口播原画” |

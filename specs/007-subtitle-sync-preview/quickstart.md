# Quickstart & Verification Guide: 字幕实时保存与成片预览所见即所得同步

**Feature**: `007-subtitle-sync-preview`  
**Date**: 2026-09-19  

## 1. 验证目标 (Validation Objectives)

1. 验证字幕列表文本修改具备清晰的状态反馈（“保存中” → “✓ 已保存”）；
2. 验证输入失焦或回车立即提交，刷新页面后确认数据不丢失；
3. 验证点击“生成预览”前自动提交未完成保存的最新内容，渲染后的 MP4 中包含最新文字且无浏览器缓存停滞；
4. 验证实时编辑器的虚拟字幕与合成导出的成片字幕在字号大小、行距及折行断句上保持 1:1 所见即所得。

## 3. 端到端手动验证流程 (Manual E2E Walkthrough)

### 流程 1: 字幕即时保存与失焦验证
1. 打开浏览器访问 `http://localhost:5173` 并进入剪辑工作台；
2. 在右侧字幕列表中选取第 1 句字幕，将其内容修改为：`“在杭州考一个驾照到底要花多少钱”`；
3. 观察右上角或字幕卡片顶部即时显示 `● 正在保存...`，失焦或回车后立即变为 `✓ 已保存`；
4. 按 `F5` 刷新页面，检查该字幕内容，确认内容仍为修改后的文字。

### 流程 2: 生成预览前置同步与防缓存验证
1. 将第 2 句字幕修改为：`“千万别找黑中介坑钱”`；
2. 立即（无需等待或失焦）直接点击顶部 `⚡ 渲染合成 / 生成预览` 按钮；
3. 观察合成中提示与控制台日志，确认请求已先同步该字幕并落库，紧接着执行 FFmpeg 压制；
4. 渲染完成后自动切入成片模式，播放该时间段，确认视频画面中烧录的字幕正是 `“千万别找黑中介坑钱”`。

### 流程 3: 字号所见即所得（WYSIWYG）对齐验证
1. 在策略工坊中将字幕字号调节为 `大号 (86px)` 或 `小号 (56px)`；
2. 切换到实时交互预览模式，记录字幕占画面宽度和高度的视觉比例以及折行情况；
3. 点击“生成预览”重新压制成片，切换至成片模式播放；
4. 比对同一时刻的成片字幕与交互预览字幕，验证字号、位置与折行点完全重合。

# Feature Specification: 015-text-behind-person-cover (人后拱形 3D 穿插爆款封面模板与 Canvas 分层渲染体系)

**Feature Branch**: `015-text-behind-person-cover`  
**Created**: 2026-09-24  
**Status**: Ready for Planning  
**Input**: 用户要求复刻小红书/抖音高点击同城 IP 封面，实现“文字在人后（Text Behind Image）+ 人像抠图置顶带纯白贴纸发光 + 逐字独立凹凸起伏描边 + 彩虹拱形环抱头顶 + 柠檬黄高饱和转化大字”，并明确采用方案 A（前端 Canvas 分层渲染与开源成熟体系）。

---

## User Scenarios & Testing *(mandatory)*

### User Story 1 - 前端 Canvas 实时渲染“文字在人后”爆款封面 (Priority: P1)

作为短视频创作者，在进入封面设计工作区时，我希望选择“👑 人后穿插拱形字”模板后，画面上的地域大字（如“杭州学车”）能自然呈彩虹拱形环绕并穿插在人物头顶后方，人物头部及上半身置顶覆盖在大字之上并带有一圈亮丽的纯白贴纸描边，字与字之间呼吸独立、描边随笔画紧密凹凸，底部呈现吸睛的亮黄色转化大字，且在调整文案或位置时能够在前端 60fps 实时流畅预览。

**Why this priority**: 这是用户本次需求最核心的视觉诉求（1:1 复刻参考爆款封面，杜绝平面死板感，确立 3D 空间穿插感）。

**Independent Test**: 在前端选择该模板，上传或选择候选帧，Canvas 能正确分层（底层全图 → 中层拱形文字 → 顶层人像贴纸带白光 → 前景标签与黄色大字），可独立验证视觉还原度。

**Acceptance Scenarios**:
1. **Given** 用户在封面编辑器选择 `text_behind_person` 模板，**When** 载入包含人物的视频底图与人物透明图层，**Then** Canvas 渲染出“文字在人后”效果，人物头顶与墨镜自然遮挡大字下边缘。
2. **Given** 顶部输入“杭州学车”4字，**When** 渲染拱形字时，**Then** 中间两字抬高、两端外倾（-9° ~ +9°），每个字独立渲染描边，字与字间不产生大长条死板黏连。
3. **Given** 人像顶层渲染时，**Then** 人像轮廓周围具备 8~12px 的纯白发光贴纸轮廓，与背景和后方文字清晰剥离。
4. **Given** 底部文案为“2980全公开”，**Then** 字芯为高饱和柠檬黄（#FFEE0A），外围为皇家宝蓝厚描边与柔和白边。

---

### User Story 2 - 视频截帧与人物图层自动轻量协同 (Priority: P2)

作为用户，当我点击时间轴截取视频画面作为封面，或者切换候选帧时，系统应当自动准备好当前帧的底图与对应的人物透明图层（Foreground Cutout），无需用户手动去抠图。

**Why this priority**: 保证 C 端小白用户的极致开箱即用体验（Zero-Terminal、零门槛自动化），无需用户先在第三方软件中抠图。

**Independent Test**: 在编辑器中选择任意视频时间戳截帧，系统生成底图同时生成对应的透明人物蒙版图，前端立即获取并注入 Canvas 渲染通道。

**Acceptance Scenarios**:
1. **Given** 用户选择时间戳截帧，**When** 触发抽帧请求，**Then** 系统秒级完成抽帧并产出透明人像 PNG，前端无感直接合成。
2. **Given** 若某些极端帧（无人物纯空镜）无法提取有效人物，**Then** 系统自动降级为“优雅前景文字”，不报错不崩溃。

---

### User Story 3 - 导出与成片第一帧嵌入 1:1 像素级一致 (Priority: P3)

作为用户，当我对当前封面满意并点击“保存封面”或“导出视频嵌入第一帧”时，后端输出的 1080×1920 印刷级封面必须与前端 Canvas 预览所见即所得、完全一致。

**Why this priority**: 杜绝“前端预览很美、导出成片变形错位”的坏体验。

**Independent Test**: 导出封面图片，与前端 Canvas 渲染的像素比例、字重、颜色、图层层级进行像素级对比，视觉表现完全一致。

**Acceptance Scenarios**:
1. **Given** 前端调整好的封面配置，**When** 调用后端生成封面或导出视频，**Then** 后端以同样的图层层级（背景 → 拱形字 → 人像带白边 → 前景大字）渲染输出高清 1080×1920 封面。

---

## Edge Cases

- **空镜/无人像帧**：若所选视频帧完全没有人物或人物遮挡不明显，系统自动平滑回退为不遮挡的完整拱形文字，不会产生黑边或透明缺块。
- **超长标题**：若地域词输入 6 个字以上（如“杭州余杭临平学车”），拱形曲率自动微调平缓，字符自适应缩小字号，防止两端字符出画。
- **透明图层加载延迟**：在网络或加载过程中，Canvas 先完整渲染背景与文字，待人像图层加载完成后平滑淡入置顶，保证界面毫无卡顿白屏。

## Requirements *(mandatory)*

### Functional Requirements

- **FR-001**: 前端 `CoverPreviewSelector.tsx` 必须注册并支持 `text_behind_person`（人后拱形 3D 穿插款）模板。
- **FR-002**: 前端 Canvas 必须实现四层绘制管线：底层视频帧 → 中层拱形逐字贴纸文字（纯白+宝蓝） → 顶层人像贴纸（带纯白光晕） → 最顶层信息（斜角卡片+底部柠檬黄大字）。
- **FR-003**: 拱形文字必须采用逐字独立绘制算法，每个字角度按拱形正弦/抛物线分布，描边必须紧贴笔画凹凸，字距适度展开，杜绝整块扁平黏连。
- **FR-004**: 必须支持通过透明人像 PNG 作为前端 Canvas 的覆盖层，前端通过 `ctx.shadowColor` 与分层混合实现人物贴纸白边。
- **FR-005**: 后端 `cover_generator.py` 必须同步支持 `text_behind_person` 模板渲染，保证导出 1080×1920 画面与前端 100% 镜像一致。
- **FR-006**: 后端提供或扩展轻量的人像图层接口，保证选帧时前端能直接读取前景透明人像。

# 快速启动与验证指南 (Quickstart & Validation Guide)

**Feature**: `001-driving-school-video-cut`  
**Date**: 2026-09-15  

---

## 1. 运行环境先决条件 (Prerequisites)

- **操作系统**：Windows 10/11 64位 或 macOS 12+ (Intel / Apple Silicon)
- **底层依赖**：
  - Python 3.10+ (推荐 3.11，当前环境：`Python 3.11.15`)
  - FFmpeg 6.0+（系统环境变量中包含 `ffmpeg` 与 `ffprobe`）
  - Node.js 18+ (用于前端构建，若使用静态产物打包则无需独立 Node 运行时)

---

## 2. 免终端一键启动验证 (Zero-Terminal Launch)

面向 C 端用户，软件提供双端独立桌面启动入口：

### Windows 双击启动
- 运行桌面启动入口 `start_app.vbs`（或打包后的可执行程序 `VideoCut.exe`）：
  - 内部静默调用 `pythonw launcher.py`，后台拉起 FastAPI 服务与本地独立桌面视窗（Edge WebView2）。
  - **验证指标**：无黑框控制台弹出，桌面直接弹出 16:9 浅色质感主界面。

### macOS 双击启动
- 双击 `VideoCut.app`（或快捷入口）：
  - 启动系统默认 WebKit 桌面视窗并加载本地工作台。
  - **验证指标**：在 Dock 栏正常显示应用图标，单窗体独立运行。

---

## 3. 端到端功能链路验证场景 (End-to-End Test Scenarios)

### 场景一：素材归集与四分类上传测试
1. 进入主界面点击顶部导航 **素材库 (Asset Library)**。
2. 将一段场地视频拖入“场地视频”卡片。
3. **验证预期**：
   - 磁盘路径 `storage/materials/venue/` 中新增对应视频文件。
   - 界面上显示该视频封面、时长、分辨率为 `1080x1920`。

### 场景二：口播 ASR 提取与驾校专有词 LLM 纠错测试
1. 在 **剪辑工作台 (Video Editor)** 上传口播视频（包含口语词：“今天在训练场给大家讲科二倒库，价格很透明，体检非常方便”）。
2. 点击 **AI 智能识别与初剪**。
3. **验证预期**：
   - ASR 提取毫秒级时间戳。
   - LLM 校正将错别字（如“科二道库”修正为“科目二倒库”）。
   - 右侧列表展示格式化字幕卡片，关键词（“训练场”、“科二”、“价格”、“体检”）被自动高亮并打上对应空镜替换标签。

### 场景三：双轨声画分离（J/L-Cut）合成与播放验证
1. 在右侧时间轴点击修改第 1 条字幕文本，左侧播放器画面同步刷新。
2. 点击底部 **生成预览** 按钮。
3. **验证预期**：
   - 口播原声音频持续平滑播放。
   - 在“训练场”对应时间区间内，画面平滑切入场地素材；区间结束后自动切回口播人像。
   - 画面底部烧录清晰的双行或单行高亮字幕。

### 场景四：硬件资源动态感知与批量混剪测试
1. 点击顶部导航 **批量生产 (Batch Production)**。
2. 界面右上角显示当前机器硬件探测结果（如：“已检测到 16 核 CPU，可用内存 22GB，建议并发数 4”）。
3. 勾选 3 个口播视频，点击 **一键生成 6 条不同混剪版本**。
4. **验证预期**：
   - 系统动态以不超过建议并发数（如 3~4 并发）平稳调度 FFmpeg 渲染。
   - 系统无任何假死或内存泄漏，渲染完成后列表提供全部视频的成品下载与一键播放。

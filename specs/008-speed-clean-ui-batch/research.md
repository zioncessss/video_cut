# Research & Decisions: 视频编辑倍速、Taste UI 极简去繁与批量混剪重构 (008)

## 1. 视频剪辑变速（FFmpeg 滤镜与声画字幕对齐）

### 决策
- **实现方案**:
  - 音频加速：使用 FFmpeg `atempo=speed` 滤镜（0.5 ≤ speed ≤ 2.0），自动保留音频原调（Pitch Correction），杜绝变调（花栗鼠音）。
  - 画面加速：在口播视频输入流应用 `setpts=(1.0/speed)*PTS`。
  - 时间轴与时间戳等比缩放：在 Python 层面，进入合成器前将所有字幕起止时间（`start_time`, `end_time`）及词级时间戳（`words`）除以 `speed`；将所有空镜切片时间（`broll_cuts`）除以 `speed`。
- **优点**:
  - 极低算力开销，单次编码完成，无多步转码损失；
  - 字幕 ASS/SRT 与空镜切点在加速后与音频真人发音 100% 毫秒级对齐。
- **替代方案对比**:
  - *方案 B：先加速原片生成临时中间视频，再对中间视频做 ASR 和切分*。缺点：引入二次转码画质损失，耗时翻倍，增加无谓磁盘 IO。选择方案 A。

### 档位设计
- 短视频爆款经验推荐档位：
  - `1.0x`：原速（默认）
  - `1.1x`：紧凑微快（完播率黄金档，短视频最推荐）
  - `1.15x`：轻快流畅（适合略带停顿的平铺直叙）
  - `1.2x`：节奏干脆（适合信息密集型干货口播）
  - `1.25x`：极速快嘴（适合快节奏带货/反转段子）

## 2. Taste-Skill 界面审计与去油腻极简减法

### 决策
依据 `Leonxlnx/taste-skill`（Anti-Slop 前端规范）：
1. **色彩与质感**:
   - 移除所有廉价的多彩渐变（AI 紫、粉蓝渐变）与发光动画。
   - 收敛为单一品牌强调色：高端靛蓝 `#4F46E5` / `#2563EB`，搭配中性白底、浅灰背景与细微边框（`border-gray-200/80`）。
2. **文字与文案减法（Ruthless Copy Decluttering）**:
   - 彻底删除括号内自述性冗余解释（如 `(自动分配独立工程目录)`、`(一个个排列的视频卡片)`、`(支持多选批量上传)` 等）。
   - 移除自嗨型 AI 状态提示段落（如 `已秒级载入工程...`、`ASR 识别准确度极高，未发现需要修正的同音错字...`），改为极简的短反馈状态或直接省略。
   - 按钮标签统一为 2~4 个字，单行无折行：`智能初剪`、`导出成片`、`上传封面`、`截取封面`。
3. **模式切换**:
   - 将原显眼的蓝色信息条 `当前预览：实时交互编辑模式（画布可拖拽）` 替换为紧凑的 iOS 风格 Segmented Switch：`[ 实时编辑 | 成片预览 ]`，状态一目了然，腾出宝贵屏幕高度。

## 3. 10年资深专家级批量混剪工作台（BatchCut）重构

### 决策
作为 10 年经验产品经理与设计专家，对批量生产场景进行系统级升维重构：
1. **双模态工作区（Tabs 切换）**:
   - **成片画廊（Gallery - 默认视图）**：创作者打开批量页面的终极目标是看交付成片。卡片采用 16:9 / 9:16 自适应瀑布流，支持 Hover 静音预览播放、标题、时长、分镜数标签、一键在编辑器微调、复制绝对路径、打开系统文件夹。
   - **混剪队列（Queue）**：当前批次与历史批次任务看板，卡片式展示每个视频当前阶段（提取音频 → ASR 识别 → 智能分镜 → 复合压制 → 完成），提供清晰进度百分比。
2. **生产控制台（Command Bar）**:
   - 常驻页面顶部，集成：画幅切换（9:16 / 16:9）、批处理倍速（1.0x / 1.1x / 1.2x）、并发设定、一键导入按钮。
3. **硬件指示器重塑**:
   - 彻底取消占满横屏的 4 块巨大硬件卡片，将其收纳为控制栏右上角的不起眼状态芯片（`● 8核 CPU · 16G 可用 · GPU 加速就绪`），既提供硬件安全感，又不侵占生产空间。
